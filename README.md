# Python Exercises Assignment

Solutions to 29 Python exercises plus a mini project, covering basic syntax, 
data type conversions, operators, conditionals, and string operations.

## Structure

- `part_a_basic_syntax/` — variables, printing, type checking, string concatenation
- `part_b_data_conversions/` — converting between str, int, float, bool, list, dict
- `part_c_operators/` — arithmetic, comparison, logical, assignment, bitwise operators
- `part_d_conditionals/` — if-else logic: even/odd, largest number, leap year, grade classifier
- `part_e_string_operations/` — string methods: split, join, replace, title case, and more
- `mini_project_palindrome_checker.py` — combines variables, string operations, and conditionals

## How to run

Each file is standalone. Run any of them directly:

​```
python part_a_basic_syntax/exercise_01_declare_print.py
​```
